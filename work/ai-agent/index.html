AI / Agentic product design

Designing an AI agent that’s honest about what it doesn’t know

AI outputs carry uncertainty, and users need to see that without losing trust in the product. This is a persistent agent that follows enterprise users through their journey, still in concept design, and the decisions behind showing model outputs honestly.

In one minute

SituationEnterprise users had to act on model outputs that a normal dashboard would show as plain numbers, with no sign of what the model was guessing.
What I didWorked with ML engineers to separate what the model knew from what it estimated, then designed confidence tiers, an agent that holds context across the journey, and failure states.
OutcomeA concept the team can build toward, with the confidence language tied to what the model scores actually mean.

Decisions

Decision 01 / 03

Show confidence without statistical jargon

A bare number creates false precision, the full distribution overwhelms, and constant hedging makes the output useless. I designed tiered disclosure: high-confidence outputs show cleanly, lower-confidence ones carry a visible signal built into the component, with a path to understand why.

Mapping the thresholds with the ML team kept the interface’s confidence language true to what the scores actually meant.

Hide the uncertainty and the product feels broken the first time the model is wrong and users realize they were never told.Design principle, AI output surfaces
Decision 02 / 03

Ambient by default, present on demand

I mapped the journey to find where an aware agent would cut real friction: transitions between tools, points of failure, and decisions that sent users elsewhere to look something up. The agent stays quiet until needed, and at high-stakes moments it confirms what it assumes before acting.

Decision 03 / 03

Design the “I don’t know”

Working sessions with ML engineers pinned down what the model could and couldn’t explain about its own outputs. That became a vocabulary for explainability, and each failure state (unavailable, low-signal, out-of-distribution) got its own copy and recovery path.
